# macos/setup-app

Development-build SwiftUI status/setup app. Runs without installing a
LaunchAgent, requesting Location permission, or requiring a root helper.
Pairing status, real permission workflow, and notarized packaging are
TB05/TB08/R01 work.

```sh
./dev build macos
./dev check macos
./dev run macos
```
