## Outcome

The Agents card distinguishes supported same-user process presence from no process, with activity unknown unless an accepted source supports more.

## Proposed ownership

Own Host process-presence adapters, process fixtures, and `firmware/ui/agents/`. Consume C02 metric and renderer interfaces.

## Scope

Implement exact resolved executable/bundle identity for the supported agents in [agent integrations](../agent-integrations.md) and [Host metrics](../host-metrics.md). Send bounded presence results at the accepted cadence.

## Resolve before promotion

Validate supported installation paths, bundle helpers, symlinks, process-exit races, and unavailable process metadata on the supported macOS version. Keep semantic activity/usage adapters deferred.

## Acceptance outline

- Same-named unrelated or other-user processes do not count as supported agents.
- Running without an activity source appears as activity unknown.
- Collection never reads arguments, prompts, conversations, source contents, or credentials.
- Availability, freshness, and adapter enablement stay distinct.

## Verification to specify

Use sanitized process-identity fixtures, agent-state replay, and real local process start/stop observations without retaining private content. Record exact fixture/scenario names, commands, and evidence paths when promoting this ticket.
