# R01 — Install and remove a signed macOS appliance package

- **Kind:** Release tracer bullet
- **Detail:** Outline
- **Status:** Not started
- **Milestones:** M7
- **Depends on:** [TB08](TB08.md), [TB17](TB17.md), [TB18](TB18.md)
- **Board:** Exclusive clean-install pairing smoke

Read [dispatch and completion rules](README.md#dispatch-and-completion). Refine this outline against prerequisite evidence before dispatch; it is not yet executable.

## Outcome

A fresh supported Mac installs a signed/notarized setup application and per-user service, pairs successfully, and removes software without silently erasing device data.

## Proposed ownership

Own macOS package/signing/notarization scripts, packaging CI, LaunchAgent release lifecycle integration, and install/removal evidence. Consume existing service/setup modules.

## Scope

Build release artifacts, independent component version metadata, source/license/notices, installation docs, and separate software/configuration/unpair/device-erase actions. Exclude the V2 privileged helper.

## Resolve before promotion

Identify Developer ID/notarization credentials and clean-machine test access; missing access remains an external blocker with a concrete runbook, not an unsigned substitute for release acceptance. Define package identity, upgrade behavior, and per-user ownership.

## Acceptance outline

- Clean install and removal pass on the declared Apple Silicon macOS support matrix.
- Signed/notarized status and component identities are verified.
- Service/pairing survive upgrade as specified and uninstall leaves device-owned Radio History intact unless explicitly erased.
- Source artifacts exclude unlicensed vendor caches and include required license/notices.

## Verification to specify

Use packaging checks, signature/notarization verification, and recorded fresh-machine install/upgrade/remove runs with physical pairing. Record exact fixture/scenario names, commands, and evidence paths when promoting this ticket.
