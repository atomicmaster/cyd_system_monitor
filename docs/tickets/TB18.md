# TB18 — Export diagnostics and erase only explicitly selected data

- **Kind:** Tracer bullet
- **Detail:** Outline
- **Status:** Not started
- **Milestones:** M6, M7
- **Depends on:** [TB13](TB13.md), [TB16](TB16.md)
- **Board:** Exclusive export/erase/recovery session

Read [dispatch and completion rules](README.md#dispatch-and-completion). Refine this outline against prerequisite evidence before dispatch; it is not yet executable.

## Outcome

The Operator can export bounded diagnostics or Radio History and explicitly erase/unpair/reset the selected scope without silently deleting unrelated data.

## Proposed ownership

Own Host export/diagnostic CLI modules, bounded USB history-transfer commands, on-device disclosure/confirmation views, separated erase/reset operations, and export fixtures. Coordinate shared protocol additions with the contract owner.

## Scope

Implement versioned diagnostic bundles, rotated privacy-preserving logs, explicit Radio History export, default address redaction in diagnostics with an explicit raw-address option, and separate history erase/factory reset/unpair paths. Use the declared log age/size limits.

## Resolve before promotion

Define transfer bounds/resume or restart semantics, live-write consistency, redaction fields, confirmation behavior, corruption handling, and exactly what factory reset removes. Keep Host History storage itself deferred to V1.

## Acceptance outline

- Diagnostic default output omits raw radio addresses and private process/conversation/source content.
- Explicit raw Radio History export includes versions/evidence/coverage after on-screen disclosure.
- Erase/reset/unpair operations have distinct documented ownership and preserve unselected data.
- Exports under load remain bounded and do not silently hide observation loss.
- Routine logs honor the seven-day/50 MiB limits.

## Verification to specify

Use bundle/schema/redaction/transfer fixtures plus physical export, separate erase actions, and interrupted-operation recovery checks. Record exact fixture/scenario names, commands, and evidence paths when promoting this ticket.
