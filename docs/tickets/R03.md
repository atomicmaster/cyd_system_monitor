# R03 — Qualify the integrated MVP and publish release evidence

- **Kind:** Qualification gate
- **Detail:** Outline
- **Status:** Not started
- **Milestones:** M7
- **Depends on:** [R01](R01.md), [R02](R02.md)
- **Board:** Exclusive integrated qualification and 72-hour soak

Read [dispatch and completion rules](README.md#dispatch-and-completion). Refine this outline against prerequisite evidence before dispatch; it is not yet executable.

## Outcome

One exact release candidate satisfies every item in the MVP validation gate, with traceable evidence and no unfinished integration assumptions.

## Proposed ownership

Own qualification scenarios, evidence index, release manifest assembly, and gate reporting. Fixes go through the owning feature/module ticket; this gate does not silently change product scope or publish a release automatically.

## Scope

Run the complete [MVP validation gate](../mvp-validation.md): supported clean-machine lifecycle, all metrics/views/states, powered link loss versus power removal, session/time/clock changes, journal recovery, boundaries/benign rules, resource budgets, updates/ROM recovery, and representative soak.

## Resolve before promotion

Freeze firmware/Host/protocol/rules/profile/scheduler/capacities/permission settings and define the soak environment and false-alert adjudication method before the run. Confirm all earlier ticket evidence and required credentials/equipment; resolve failures and identify which tests need rerunning after fixes.

## Acceptance outline

- Every release criterion has a passing evidence link for the integrated candidate.
- The representative 72-hour soak has zero known false Medium/High and at most three false Low Alerts per rule; Extreme is never emitted.
- All feature and physical integration checks pass; a simulator pass does not replace physical evidence.
- The result records exact versions, capacities, measurement limits, and remaining supported-platform limitations.
- A failed or incomplete gate remains open; report a reviewable release candidate separately from any publication action.

## Verification to specify

Use `./dev check all`, complete physical/clean-machine runbooks, retained measurements, and a 72-hour soak report. This is a long-running qualification activity, not an agent claiming completion from a short smoke run. Record exact fixture/scenario names, commands, and evidence paths when promoting this ticket.
