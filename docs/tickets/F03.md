# F03 — Build the Rust Host and Swift setup targets

- **Kind:** Foundation
- **Detail:** Executable
- **Status:** Done
- **Milestones:** M0
- **Depends on:** [F01](F01.md)
- **Board:** None

Read [dispatch and completion rules](README.md#dispatch-and-completion) before starting. Command names below are planned deliverables, not tools that already exist.

## Outcome

A pinned Rust workspace and SwiftUI setup target build and run on supported Apple Silicon macOS, independently of the firmware lane.

## Ownership and inputs

Own `host/` workspace/build scaffolding, `macos/setup-app/` scaffolding, and `tools/dev/{host,macos}.sh`. F02 owns C++/desktop work and F04 owns shared CI. Follow the [macOS design](../macos-components.md).

## Work

1. Pin Rust and the Xcode/Swift environment and document acquisition/setup where a human login or license acceptance is required.
2. Create empty daemon and CLI targets with a portable metric seam and a macOS adapter home. Reserve separate modules for protocol, transport, and per-metric collectors; defer concrete collectors to tracer tickets.
3. Create a minimal development-build SwiftUI status application. Keep developer signing needs explicit; notarized release packaging belongs to R01.
4. Provide build/check/run commands, formatting, and scoped dependency/license notices.

## Acceptance

- CLI help and the empty setup app run without installing a LaunchAgent, requesting Location permission, or requiring a root helper.
- The daemon skeleton exits cleanly and does not contact external services.
- No GPU/ANE collector or privileged-helper executable is added; those belong to V2.
- Build and test targets work without firmware sources or ignored vendor files.

## Verification and handoff

Run `./dev build host`, `./dev build macos`, `./dev check host`, `./dev check macos`, and `./dev run host -- --help`. Launch the development setup app and record the toolchain/build identity. Supply F04 with deterministic command and dependency requirements.

## Evidence

Base commit `f21678d`; result commit `ab1094a` (workspace also extended with `transport`/`protocol` crates in `6da0a8f`'s follow-on review fixes). Rust 1.97.1 pinned in `rust-toolchain.toml`; `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test` all pass across `daemon`, `cli`, `metrics`, `platform-macos`, `transport`, and `protocol`. `swift build` produces the SwiftUI setup app (Swift 6.4 / Xcode 16+) with no LaunchAgent install, Location permission request, or root helper.
