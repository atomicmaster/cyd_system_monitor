# F07 — Exercise the remaining board peripherals

- **Kind:** Hardware feasibility
- **Detail:** Executable
- **Status:** Not started
- **Milestones:** M1
- **Depends on:** [F05](F05.md)
- **Board:** Exclusive E32R28T session

Read [dispatch and completion rules](README.md#dispatch-and-completion) before starting. Command names below are planned deliverables, not tools that already exist.

## Outcome

The diagnostic image exercises the remaining profile capabilities and distinguishes measured behavior from vendor claims before combined-load validation.

## Ownership and inputs

Own RGB LED, audio-enable/DAC, MicroSD probe, battery-ADC diagnostic, button/expansion probe adapters, and their profile evidence. F06 owns touch/calibration. Both consume the diagnostic screen through separate diagnostic modules; the integration owner registers them serially.

## Work

1. Exercise each remaining vendor-claimed pin safely in its documented role, respecting input-only and boot-strapping constraints.
2. Verify GPIO4 amplifier-enable behavior on the fitted board and exercise optional sound deliberately; its product default remains off.
3. Probe MicroSD and shared expansion SPI, record the provisional bus allocation, and expose board voltage as diagnostic data only.
4. Record reset/button behavior and equipment/operator steps needed to validate expansion signals. An unexercised pin remains an open result, not a passed claim.

## Acceptance

- LEDs, optional audio, storage presence/failure, and ADC diagnostics are visible and reproducible.
- Missing SD is an ordinary idle status; the MVP does not acquire an SD dependency for normal operation.
- Calibration work from F06 remains intact after integration.
- M1 has evidence for every promised peripheral or an explicit resolved profile exception; remaining unverified hardware prevents declaring M1 complete.

## Verification and handoff

Run `./dev check firmware` and `./dev run hardware -- peripherals --port "$CYD_PORT"`. Attach the pin/capability result table, build identity, and optional external-equipment steps. F06 and F07 may develop in parallel, but flashing, port use, and diagnostic registration are serialized.
