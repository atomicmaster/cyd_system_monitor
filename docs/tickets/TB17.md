## Outcome

The integrated appliance has the promised six-card Overview, current-detail screens, first-start flow, persistent status, and About diagnostics with every accepted state reachable.

## Proposed ownership

Own UI composition/layout/navigation and visual acceptance fixtures. Feature widgets remain with their slice owners; coordinate fixes rather than rewriting their domain logic.

## Scope

Integrate graph-free System/Storage/Network/Agents/WiFi/BLE cards, readable status/banner/clock, Host Last Seen, pairing, Settings, About versions, and safe untrusted labels. Complete optional sound and redundant icon/text/shape severity cues.

## Resolve before promotion

Resolve actual text/touch dimensions, shared status priorities, layout composition, and performance evidence using the real integrated firmware. Identify any missing domain state by its owning ticket rather than hiding it in UI logic.

## Acceptance outline

- Overview uses no scrolling/graphs and all detail/back/status interactions work on 320×240.
- Cold boot, unavailable/stale metrics, outside-band coverage, interrupted/unassessable Alerts, disabled radios, and incompatible versions have visual fixtures.
- First start reaches Overview without a daemon or a mandatory channel-plan choice.
- Touch/animation budgets pass under representative radio/USB load, with coverage recorded.

## Verification to specify

Use full simulator scenario/visual review, accessibility checks appropriate to the display, and physical navigation/load measurements. Record exact fixture/scenario names, commands, and evidence paths when promoting this ticket.
