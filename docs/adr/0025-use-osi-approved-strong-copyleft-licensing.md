# Use OSI-approved strong copyleft licensing

Superseded in part by [ADR 0027](0027-license-firmware-under-apache-2-0.md): the firmware image is licensed `Apache-2.0`, not `GPL-3.0-only`, for the reasons recorded there. This decision otherwise stands for the rest of project-authored software.

Project-authored software will use GNU General Public License version 3 only, identified as `GPL-3.0-only`. It is an OSI-approved open-source license and therefore permits commercial use, modification, and redistribution. Its strong copyleft terms keep redistributed modified software and corresponding source under the same freedoms, which most closely preserves the project's earlier preference against closed commercial derivatives while remaining accurately open source.

Project-authored documentation will use Creative Commons Attribution-ShareAlike 4.0, identified as `CC-BY-SA-4.0`. Source and documentation files will carry appropriate SPDX identifiers, release artifacts will include applicable license texts and corresponding-source information, and dependency notices will be preserved. Cached vendor archives, component datasheets, photos, design files, and other third-party material are governed by their owners' terms and are excluded from the project license and source distributions unless redistribution permission is documented.
